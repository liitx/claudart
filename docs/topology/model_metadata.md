# Model metadata topology

> Generated by `make topology` from the code. Do not edit by hand: a test fails when this file and the code disagree.

Three kinds of model information (docs/design.md 9.6): **declared** (`AgentModel`, below), **resolved** (the machine's alias mapping, re-read at launch) and **observed** (the `claude` stream, per step). Observation is read from the final `result` line claudart already parses, so it costs no model call and no prompt tokens.
