# Topological families

> Generated by `make topology` from the code. Do not edit by hand: a test fails when this file and the code disagree.

A family is a cell of two axes read from what a file's code does (`test/helpers/topology_family.dart`): the state role (does it emit a handoff event, only read a status, or neither) and the farthest layer it reaches. A file whose code matches no portal falls in the complement, `untouched x pure`. A name that is only declared in a file also matches, so the owner of a portal sits beside its users.
