# Proof audit

> Generated by `make proof-audit` from the rows in `proofs.jsonl`. It takes minutes, so the test suite does not check it: rerun it after a change to a matrix or to its proofs.

Each fault changes one fact of a matrix in a scratch copy. Tier 1 is the tests meant to carry the proof; tier 2 is the wider suite, run only for a fault tier 1 missed. The control faults (a comment that changes nothing must come out missed, source that does not compile must come out invalid) ran first and are not counted here.
